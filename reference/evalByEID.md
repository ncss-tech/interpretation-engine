# Extract Evaluation Curve by Evaluation ID

Extract Evaluation Curve by Evaluation ID

## Usage

``` r
evalByEID(eid, d, sig.scale = 1)

evalbyeid(eid, d, sig.scale = 1)
```

## Arguments

- eid:

  Evaluation ID – NB: not rule id or property id. Evaluation only.

- d:

  data to pass through evaluation curve?

- sig.scale:

  not used

## Value

result of evaluation made with the specified evaluation curve
