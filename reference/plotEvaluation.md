# Plot Evaluation Curve

Plot Evaluation Curve

## Usage

``` r
plotEvaluation(x, xlim = NULL, resolution = 100, pch = NA, ...)
```

## Arguments

- x:

  data

- xlim:

  `plot` xlim default `NULL`

- resolution:

  number of points (default 100)

- pch:

  point character for source domain/range values. Default: `NA`

- ...:

  additional arguments passed to plot

## Value

a plot
