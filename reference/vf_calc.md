# Valley Fever

Valley Fever

## Usage

``` r
vf_calc(indata, doxeric = "auto")
```

## Arguments

- indata:

  Input data (as data.frame or SpatRaster)

- doxeric:

  force xeric or nonxeric function, or let it choose for each data
  row/pixel depending on an input raster (accepts "auto" / "xeric" /
  "nonxeric")

## Value

Evaluation result (as data.frame or SpatRaster)
